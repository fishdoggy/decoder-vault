# 解碼局 任務庫

一個給 10 歲小孩的英文解讀遊戲。不背單字——在真實的英文文件裡，點出那句會改變決定的話，然後把它唸出來。

**線上玩：** https://fishdoggy.github.io/decoder-vault/

## 玩法

每一關給一份真實的英文材料（樂高盒、遊戲商店頁、退貨條款、論壇問答串），底下是委託人的一個問題。你要在文件上**點出答案那一行**，送出情報。答對之後，還要**唸出兩句英文**才算回報完成。

- 答錯不直接給答案，先給方向提示，第二次才揭曉
- 「解碼器」可以查關鍵字中譯，但每個賽程額度有限，要省著用
- 陷阱在小字裡：`batteries not included`、`Limit 2 per customer`、`Doors open` vs `Show starts`

## 三個賽程

| 賽程 | 關卡 | 難度 |
|---|---|---|
| 熱身 | 10 | 字很少，一眼看完。Wi-Fi 卡、零食成分、泳池告示、登機證 |
| 標準 | 8 | 真實商品頁與公告，有陷阱。樂高盒、特價頁、改版公告、票券 |
| 深層 | 3 | 整段英文，答案藏在條件句裡。論壇問答、退貨條款、報名資格 |

## 兩種發音驗收

選單上可以切換：

- **媽媽聽**（預設）— 先聽語音示範，唸給大人聽，她確認後才通過
- **麥克風 88 分** — 對著麥克風唸，程式比對辨識結果打分，88 分才過；顯示「聽到了什麼」和漏掉哪個字，三次不過可由大人放行

麥克風判定需要 https 或 localhost 才能取得權限。字尾馬虎可以通過，但每個字的主體要唸對、不能漏字。

## 本機執行

```bash
python3 -m http.server 8123
```

然後開 http://localhost:8123/
